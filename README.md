# T3 Code + OpenCode + DeepSeek V4.1 Flash Free

Готова настройка за Android, без собствен компютър. Активният вариант използва
Railway; приложението на телефона управлява задачите.

[Настройката за Railway](server/README.md) позволява на асистента
да управлява разполагането след добавяне на Railway интеграцията и вход в твоя
акаунт. За него има Docker образ, постоянен диск и автоматичен каталог на всички
модели с нулеви цени в OpenCode. DeepSeek остава избран по
подразбиране. Един общ OpenCode процес обслужва разговорите и помощните операции,
за да се вмести в пробния сървър. Разполагането е проверено с HTTPS/WSS връзка и
реален отговор от модела. Безплатният кредит за хостинга е ограничен;
проверената конфигурация изисква поне 1 GB RAM, колкото позволява пробният план.

Railway вариантът използва T3 **0.1.0** с протокол **2** и OpenCode **2.0.32**,
съвместими с обновеното Android приложение 2.0. След обновяване затвори и отвори
приложението, после избери
**Refresh models** в настройките на разговора. Адресът и сдвояването се запазват.

За няколко отворени разговора има обща опашка: едновременно се изпълнява една
заявка към модел, а останалите изчакват автоматично. Това обхваща безплатните
модели и NVIDIA. Възстановените след срив задачи остават в историята и могат
да се продължат от същия разговор. Кешовете са извън постоянния диск, логовете
са ограничени, а резервът за диска пази място за историята. При достигането му
новите заявки спират с грешка за мястото; не се изтриват разговори или проекти.

## Архивен вариант за Codespaces и V1 приложението

Следващите стъпки използват стария протокол и не са за Android 2.0.

1. Отвори [създаването на Codespace](https://github.com/codespaces/new?hide_repo_select=true&ref=main&repo=1421395005).
   Избери **2-core** и **Create codespace**. При нужда включи **Desktop site** в Chrome.
2. Изчакай инсталацията. В терминала долу постави:

   ```bash
   bash .devcontainer/finish-setup.sh
   ```

3. В Android приложението отвори **Add Environment** и копирай изписаните
   **HOST** и **PAIRING CODE**. Кодът важи веднъж за 15 минути. Ако настройката
   за публичния порт не мине автоматично: **PORTS → 3773 → Port Visibility → Public**.
   Публичен е адресът на T3 Code; достъпът до средата изисква сдвояване.
4. Създай разговор с **OpenCode → DeepSeek V4.1 Flash Free**. Проектът е добавен
   автоматично. Ако моделът липсва, избери **Refresh models** в настройките на разговора.

Ако вече имаш стар Codespace за това хранилище: изпълни `git pull --ff-only`,
после **Command Palette → Codespaces: Rebuild Container**. За първа употреба
предпочети нов Codespace, ако в стария няма незапазени файлове.

При повторно включване на същия Codespace сървърът стартира автоматично.
Телефонът запазва сдвояването. За нов код изпълни отново командата от стъпка 2.

## T3 Connect по желание

За връзка през собствения relay на T3 вместо публичния GitHub порт:

```bash
bash .devcontainer/finish-setup.sh --connect
```

Отвори официалния линк, потвърди кода и разреши изтеглянето на tunnel helper,
ако програмата попита. Рестартирай Codespace-а и в Android влез в същия T3 Connect
акаунт. Този вариант не изисква ръчно въвеждане на HOST и PAIRING CODE.

## Безплатна квота и запазване на работата

- GitHub Free включва **120 core-hours**, тоест до **60 часа** с 2-core машина
  месечно, и **15 GB-month** за съхранение. Това не е безплатен сървър 24/7.
- Спирай средата след работа: [github.com/codespaces](https://github.com/codespaces)
  → менюто с трите точки → **Stop codespace**. Спирането пази файловете.
- При липса на активност Codespaces обикновено спира след 30 минути. Отвори
  отново същата среда през горния линк. Изтриването на средата изтрива локалната
  история и незапазените в GitHub файлове. Прилагат се и настройките за автоматично
  изтриване на неактивни Codespaces.
- Ако няма платежен метод, GitHub блокира работа след изчерпване на квотата.
  Ако вече имаш платежен метод, провери бюджета за Codespaces, за да не преминеш
  към платено потребление. Дисковото пространство се отчита и при спряна среда.
- Безплатният модел е **`opencode/deepseek-v4.1-flash-free`**. Вариантът без
  `-free` е платен. Настройката избира само безплатния модел, включително за
  заглавия, без API ключ. Безплатната оферта е временна и има ограничения.

## Какво е настроено

По-старият вариант за Codespaces използва T3 Code **0.0.45** и OpenCode **1.19.1**
и е за V1 приложението. За Android 2.0 ползвай актуализирания Railway вариант.
OpenCode е включен в T3, безплатният модел е избран по подразбиране.
OpenCode 1.x и 2.x не споделят база в тази настройка.
Инструментите, настройките и историята са в `/workspaces/.t3-phone`, извън Git,
и оцеляват при нормално спиране и rebuild на същия Codespace. Пази pairing кодовете
само при себе си. Не добавяй тази папка към публично хранилище.

# T3 Code за Android + OpenCode

Сървърът използва T3 Code **0.1.0**, протокол **2**, и OpenCode **2.2.5**.
Android приложението се свързва с HTTPS адрес и еднократен pairing code.

## GitHub Codespaces

Настройката в `.devcontainer` инсталира същите проверени версии като Docker
варианта. Кодът и историята са отделни: постоянните данни се пазят в
`/workspaces/.t3-code/data`, извън Git. Нормално спиране и rebuild на същия
Codespace запазват тази папка. Изтриването на Codespace я изтрива.

При създаване се изпълнява `scripts/codespaces-setup.sh`; при всяко пускане —
`scripts/codespaces-start.sh`. T3 и един общ OpenCode процес стартират автоматично.
При срив на процес се прави повторен опит с нарастваща пауза. Тази защита работи
само докато самият Codespace е включен.

За ново сдвояване отвори терминала на средата и изпълни:

```bash
bash scripts/codespaces-pair.sh
```

В телефона избери **Add environment** и постави изписаните **HOST** и
**PAIRING CODE**. Само порт **3773** се отваря публично; достъпът изисква
сдвояване. Паролата и вътрешният порт на OpenCode остават локални.

Личният GitHub Free план включва **120 core-hours** месечно, приблизително
**60 часа** с машина с 2 ядра, и **15 GB-month** за съхранение. Това е квота за
работа при нужда. Няма обещание за безплатен сървър 24/7. По подразбиране средата
спира след около 30 минути неактивност. Отвори същата среда през
[github.com/codespaces](https://github.com/codespaces), за да продължиш.
След работа използвай **Stop codespace**. Следи и настройката за автоматично
изтриване на неактивни среди. Дискът се отчита и когато машината е спряна.

Настройката не добавя платежен метод и не увеличава бюджет. При липса на такъв
GitHub блокира работа след изчерпване на квотата. Ако вече имаш платежен метод,
провери бюджета за Codespaces преди пускане, за да предотвратиш платено потребление.

## Ключове и модели

Добавяй ключове само в [Codespaces secrets](https://github.com/settings/codespaces)
с достъп до това хранилище. След промяна рестартирай Codespace, за да ги получи
сървърът. Не ги изпращай в чат и не ги записвай в Git.

| Услуга | Име на secret |
| --- | --- |
| NVIDIA NIM | `NVIDIA_API_KEY` |
| Groq | `GROQ_API_KEY` |
| Moonshot API | `MOONSHOT_API_KEY` |
| Kimi Code | `KIMI_API_KEY` |
| AMD Radeon Token Factory (Китай) | `AMD_RADEON_API_KEY` |
| ModelScope | `MODELSCOPE_API_KEY` |
| OpenRouter, само безплатният каталог | `OPENROUTER_API_KEY` |

AMD ключът от `developer.amd.com.cn/radeon/tokenfactory` използва единствено
`https://developer.amd.com.cn/radeon/api/v1`. Глобалният AMD Token Lab е друга
услуга. Проверяват се актуалният каталог и поддръжката на streaming и инструменти.
Поддържаните API идентификатори са `DeepSeek-V4.1-Flash`, `Qwen3.8-Flash-Next`,
`Qwen3.8-27B`, `GLM-5.3-Flash`, `MiMo-V2.6-Flash`. Видимите модели зависят от
правата и каталога на акаунта. AMD дава пробен достъп с дневни точки и лимити;
нулевата парична цена не означава неограничено ползване. Защитата не включва
автоматично платени модели.

В T3 използвай **Refresh models** след добавяне на ключ. Всички услуги споделят
една опашка за заявки; историята, инструментите и автоматичните разрешения се
обслужват от същия сървър. Лимитите на доставчиците остават валидни.

## Съществуващата среда в Railway

[Docker настройката и защитите за историята](server/README.md) остават налични.
Railway спря последния работещ контейнер след изтичане на пробния план и отказва
ново разполагане без план. Преминаването към Codespaces само по себе си не
копира стария диск. Не изтривай Railway volume или архивния bucket преди
проверено възстановяване на историята. По-стар архив не включва по-нови чатове.

Официални източници: [T3 Code](https://github.com/pingdotgg/t3code),
[Codespaces квоти](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces),
[AMD Radeon Cloud](https://amd-aim.github.io/radeon-cloud-docs/).
